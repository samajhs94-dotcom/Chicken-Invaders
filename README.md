# بازی Chicken Invaders

سما سیادهنی 

## امکانات پروژه

- ثبت‌نام و ورود کاربران
- هشت مرحله مختلف
- دشمن‌های عادی، سریع، زیگزاگ و تیرانداز
- مبارزه با باس در مراحل ۴ و ۸
- پاورآپ‌های مختلف
- قابلیت توقف و ادامه بازی
- تنظیم صداهای بازی
- نمایش تاریخچه امتیازها
- فروشگاه هواپیماها
- ذخیره اطلاعات در پایگاه داده SQLite

## پیش‌نیازها

برای اجرای پروژه به موارد زیر نیاز است:

- Java JDK نسخه 17 یا جدیدتر
- درایور SQLite JDBC
- نرم‌افزار IntelliJ IDEA یا یک محیط اجرای جاوا

## درایور SQLite

برای اتصال برنامه به پایگاه داده، فایل درایور SQLite JDBC باید به پروژه اضافه شود.

نمونه نام فایل درایور:

`sqlite-jdbc-3.53.2.0.jar`

مراحل اضافه‌کردن درایور در IntelliJ IDEA:

1. وارد بخش `File > Project Structure` شوید.
2. گزینه `Modules` را انتخاب کنید.
3. وارد قسمت `Dependencies` شوید.
4. روی علامت `+` کلیک کنید.
5. گزینه `JARs or Directories` را انتخاب کنید.
6. فایل درایور SQLite را اضافه کنید.

## نحوه اجرای پروژه

1. پروژه را در IntelliJ IDEA باز کنید.
2. درایور SQLite JDBC را به پروژه اضافه کنید.
3. مطمئن شوید Working Directory روی پوشه اصلی پروژه تنظیم شده است.
4. کلاس زیر را اجرا کنید:

`main.GameMain`

پوشه `src` باید در مسیر اصلی پروژه قرار داشته باشد؛ چون تصاویر و صداها از مسیر `src/resources` خوانده می‌شوند.

## کلیدهای بازی

- حرکت به چپ: کلید جهت چپ یا `A`
- حرکت به راست: کلید جهت راست یا `D`
- حرکت به بالا: کلید جهت بالا یا `W`
- حرکت به پایین: کلید جهت پایین یا `S`
- شلیک: `Space`
- توقف و ادامه بازی: `P`
- بازگشت به منوی اصلی: `Escape`

## پایگاه داده

این پروژه از پایگاه داده SQLite استفاده می‌کند.

نام فایل پایگاه داده:

`game.db`

اگر این فایل وجود نداشته باشد، هنگام اولین اجرای برنامه به‌صورت خودکار ساخته می‌شود.

جدول‌های پایگاه داده:

- جدول `users`: اطلاعات کاربران، بالاترین امتیاز، آخرین مرحله، هواپیمای انتخاب‌شده و تنظیمات صدا را ذخیره می‌کند.
- جدول `game_history`: امتیاز، مرحله، تاریخ بازی و تنظیمات صدا را برای هر بازی ذخیره می‌کند.

## ساختار پروژه

- `src/main`: کلاس اصلی اجرای برنامه
- `src/ui`: صفحه‌ها و رابط کاربری
- `src/model`: مدل کاربر و اشیای بازی
- `src/enemy`: دشمن‌ها و باس‌ها
- `src/manager`: مدیریت دیتابیس، مراحل و صداها
- `src/resources/images`: تصاویر بازی
- `src/resources/sounds`: صداهای بازی
